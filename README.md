# 🚀 Personal Portfolio Website

This is my personal portfolio website built with **React (JSX)**.  
It showcases my skills, projects, and contact information in a modern and responsive design.

---

## 🛠 Tech Stack

- **React** (JSX)
- **React Router DOM**
- **CSS / Tailwind CSS** (optional)
- **JavaScript (ES6+)**
